# PC 足球員生涯模擬器 — 願景與路線圖

## 願景

製作一款以 Windows PC 為主、流暢度優先的 3D 足球員生涯模擬遊戲。玩家建立一名自創球員，從 15 歲青訓生涯開始，透過訓練和比賽成長，爭取一隊上場機會、轉會和國家隊徵召，並一路留下完整的職業生涯紀錄。

整體生涯模式以 FIFA 球員生涯模式的內容深度為參考。比賽時玩家只操控自己的球員，隊友和對手由 AI 控制；場上提供轉播視角與球員跟隨視角，玩家可以自行選擇。世界以多國歐洲主要及次級聯賽、現實球隊為目標，並包含青年隊、成年隊和國家隊生涯。

## 已確定的設計方向

- **平台與技術目標**：Windows 桌面遊戲；優先確保流暢的 3D 比賽體驗。
- **遊戲引擎**：Unity 6.3 LTS + URP 為目前首選驗證方案；正式定案前，需與 Godot 做同規格效能樣本比較。流暢度優先，並提供可調整的畫面設定。
- **效能目標**：原型暫以 1080p、穩定 60 FPS 為目標；需在實際目標電腦上量測後確認，並提供低負載畫面選項。
- **比賽時間**：正式比賽計時維持每半場 45 分鐘；玩家實際遊玩時間預設每半場 6 分鐘，可自行調整，最高每半場 20 分鐘。
- **原型球員外觀**：先用簡單方塊人／低面數幾何造型代表球員，控制模型與材質負擔；球員外觀採可替換設計，之後再換正式模型。
- **比賽視角**：玩家可在斜上方轉播視角與第三人稱球員跟隨視角間選擇。
- **場上控制**：鍵盤操作；玩家只控制自創球員，隊友及對手由 AI 控制。
- **原型鍵盤配置**：WASD 移動、Shift 衝刺、Q 小步控球／緊密盤帶、F+方向鍵過人、J 短傳、K 穿越球、I 長傳／傳中、L 射門、F+L 假射門、空中球時 Space 頭球、E 站立攔截／搶球、C 切換鏡頭、Esc 暫停。持球移動時自然盤帶；移動方向依球隊當前進攻方向，不隨鏡頭改變；按鍵可重新配置。
- **原型過人動作**：持球時按 F+A／D 做左右假動作切球，F+W 做向前假動作接加速趟球，F+S 做急停拉回；動作受空間、速度和防守者位置影響，失敗時可能被斷球。
- **生涯起點**：球員固定 15 歲，從青訓開始。
- **球員建立**：玩家自選姓名、國籍、起始國家、位置與外型；位置可選前鋒、中場、後衛或守門員。
- **生涯成長**：能力依訓練內容、比賽表現及實際位置發展；教練可建議轉位，由玩家決定是否接受。
- **球員能力與性格**：能力值採 1–100。場上球員包含速度、加速、體力、力量、靈活、控球、盤帶、短傳、長傳、射門、頭球、搶球、視野和跑位；守門員另有撲救反應、撲救能力、接球和手腳傳球。性格包含職業態度、團隊合作、自信、紀律和抗壓。
- **訓練與成長速度**：訓練以一週為單位，由玩家選擇訓練方向並安排休息；比賽表現也影響成長。15–18 歲成長較快、19–22 歲持續成長，之後逐漸放慢；訓練、位置、表現、疲勞和傷病都會影響成長。
- **位置熟練度**：記錄主位置、副位置和各位置熟練度，轉位後逐步累積熟練度。
- **俱樂部發展**：目標範圍包含五大聯賽頂級聯賽（英格蘭英超、西班牙西甲、德國德甲、義大利義甲、法國法甲）、英格蘭英冠／英甲／英乙，以及五大聯賽國家的青年隊／青年賽事（英格蘭包含 U18、U21）。生涯包含青訓升一隊、租借、合約和轉會；歐冠與歐洲聯賽列入後續目標，待國內聯賽與資格系統完善後再加入。
- **場外生涯與性格**：包含訓練安排、教練評價、隊友互動、媒體採訪、經紀人、合約、傷病、狀態及生涯紀錄。場外選擇與事件會逐步塑造球員性格，並影響教練信任與評價、隊友關係，以及士氣、狀態和場上表現。
- **國家隊**：依球員國籍和表現，從符合年齡的青年代表隊爭取徵召；表現特別突出的球員有機會跳級進入較高齡青年隊，甚至提前獲得成年國家隊徵召。
- **現實球隊與球員**：目標版本使用五大聯賽和英格蘭英冠／英甲／英乙的現實球隊；五大聯賽與英冠使用現實球員名單，英甲與英乙可使用虛構／生成球員名單以減少資料整理負擔。五大聯賽國家的青年隊／青年賽事也納入目標（英格蘭包含 U18、U21）。現實隊名、隊徽及真實球員姓名、肖像與資料的授權和來源仍待確認；內容架構應能替換素材。

## 生涯玩法整理

### 生涯起點與球員建立

- 玩家建立一名自創球員，固定從 **15 歲青訓**開始。
- 可設定姓名、國籍、起始國家、位置與外型；位置包含前鋒、中場、後衛和守門員。
- 球員進入所選國家的球隊青訓，參加青年隊訓練與比賽，逐步爭取升上一隊。

### 成長與位置發展

- 能力依訓練內容、比賽表現及實際上場位置逐步成長。
- 場上球員能力採 1–100：速度、加速、體力、力量、靈活、控球、盤帶、短傳、長傳、射門、頭球、搶球、視野和跑位；守門員另有撲救反應、撲救能力、接球和手腳傳球。
- 性格面向先定為職業態度、團隊合作、自信、紀律和抗壓；場外事件逐步改變性格。
- 訓練以一週為單位，玩家選擇訓練方向並安排休息；比賽表現也影響成長。15–18 歲成長較快、19–22 歲持續成長，之後逐漸放慢；訓練、位置、表現、疲勞和傷病都會影響成長。
- 記錄主位置、副位置和各位置熟練度；轉換位置後逐步累積新位置熟練度。
- 教練可以提出轉位建議，由玩家決定是否接受。
- 生涯中管理疲勞、狀態、傷病、士氣和上場機會。

### 俱樂部生涯與真實名單

- 目標範圍為英超、西甲、德甲、義甲、法甲、英冠、英甲、英乙，以及五大聯賽國家的青年隊／青年賽事（英格蘭包含 U18、U21）。所有聯賽使用現實球隊；五大聯賽與英冠採現實球員名單，英甲／英乙可採虛構或生成球員名單。
- 生涯發展包括青訓升一隊、替補與先發競爭、教練信任、上場時間、合約、續約、租借和轉會；初期可出現少量外國球隊邀請。上場機會會受球員自身表現、體能與位置熟練度、同位置隊友的能力和狀態，以及教練的戰術風格、陣型和用人偏好共同影響。
- 各國青年賽事的具體組別與賽制；現實球隊與五大聯賽／英冠球員資料、姓名、隊徽和肖像的來源與授權仍待確認。

### 國家隊生涯

- 依球員國籍參加符合年齡的青年隊；教練依表現、出場時間、狀態和位置需求徵召。
- 表現突出的球員有機會跳過年齡層，直接獲得較高齡青年隊或成年國家隊徵召；跳級是機會，不保證發生。

### 場外生活、性格與關係

- 場外內容包括訓練安排、教練評價、隊友互動、媒體採訪、經紀人、合約、傷病、狀態和生涯紀錄。
- 場外選擇與事件會逐步塑造球員性格；性格再影響教練信任與評價、隊友關係，以及士氣、狀態和場上表現。

### 生涯紀錄與結尾

- 長期記錄個人生涯統計、獎項、里程碑與重要事件，最後提供退役／生涯總結。
- 歐冠與歐洲聯賽列入完整生涯內容；待國內聯賽、賽季和歐戰資格判定完善後再實作。

### 尚待決定的生涯細節

- 現實球隊與五大聯賽／英冠球員資料來源和授權；英格蘭以外青年賽事及次級聯賽的範圍；歐戰資格規則與五大聯賽以外參賽球隊資料。
- 各項能力與性格的精確影響幅度、每週訓練安排、賽季節奏、合約／轉會數值和徵召條件。
- 場外事件的具體選項、影響幅度及球員建立的其餘細節。

## 原型比賽操作（鍵盤）

| 類別 | 按鍵 | 動作 |
|---|---|---|
| 移動 | WASD | 移動球員；方向依球隊當前進攻方向，切換鏡頭不改變按鍵意思。 |
| 速度 | Shift | 衝刺；持球時為衝刺帶球。 |
| 盤帶 | 持球時 WASD | 自然帶球盤帶。 |
| 緊密控球 | 按住 Q | 小步控球，讓球保持在腳邊；移動速度較慢。 |
| 左右過人 | 持球時 F+A／F+D | 左右假動作切球。 |
| 向前過人 | 持球時 F+W | 向前假動作後趟球加速。 |
| 拉回過人 | 持球時 F+S | 急停並把球拉回。 |
| 傳球 | J | 短傳。 |
| 傳球 | K | 穿越球。 |
| 傳球 | I | 長傳／傳中。 |
| 射門 | L | 射門。 |
| 假射門 | 持球時 F+L | 做射門假動作，嘗試誘使防守者提前攔截。 |
| 頭球 | 空中球可爭頂時 Space | 依球的位置與情境嘗試頭球攻門或解圍。 |
| 防守 | E | 站立攔截／搶球；原型先不加入滑鏟。 |
| 鏡頭 | C | 切換斜上方轉播視角與第三人稱球員跟隨視角。 |
| 系統 | Esc | 暫停。 |

以上是原型預設按鍵，之後可在設定中重新配置。過人結果依速度、空間和防守者位置判定，不保證每次成功；守門員由 AI 控制。
